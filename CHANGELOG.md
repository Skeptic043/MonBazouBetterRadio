# Changelog

## 1.0.0

First public release of Better Radio.

- Song filenames replace generic track numbers, with scrolling for long names.
- Active CD radios share playback, seeking and shuffle.
- Preset 6 toggles shuffle and remembers the choice across save changes and game restarts.
- The native music folder and optional external folders are scanned recursively.
- Songs are prepared in the background, with the current and next song ready as needed.
- Supports MP3, Ogg Vorbis and PCM WAV, plus AAC, M4A and MP4 audio when Windows Media Foundation is available.
- Preserves normal FM controls, individual radio volume and temporary display messages.
